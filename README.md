## 🚀 Como Explorar

Cada pasta dentro de `/projects` contém um arquivo `README.md` específico com instruções de execução locais.

1. Escolha um projeto.
2. Siga as instruções no README da pasta.
3. Use `npm install` e `npm run dev` para subir o servidor local.
