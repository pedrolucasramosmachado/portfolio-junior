## 🛡️ Mentalidade de Engenharia

Em todos os projetos aqui presentes, aplico princípios de software profissional:
- **Segurança:** Uso rigoroso de variáveis de ambiente e arquivos `.env.example`. Nenhum segredo é exposto em commits.
- **Privacidade:** Tratamento de dados sensíveis e anonimização de marcas REAIS para proteção de propriedade intelectual.
- **Clean Documentation:** READMEs escritos como *Case Studies*, focando nos problemas resolvidos e não apenas na tecnologia.
- **Performance:** Otimização de imagens, uso de Builds modernas (Vite) e atenção ao Core Web Vitals.
