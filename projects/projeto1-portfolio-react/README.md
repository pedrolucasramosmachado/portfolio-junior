# Junior Dev Portfolio — The Main Hub 🚀

Este é o projeto que centraliza e apresenta minha jornada como desenvolvedor. Mais do que um simples currículo, é uma vitrine interativa das tecnologias que domino e dos problemas que resolvi.

![Preview Portfolio](https://images.unsplash.com/photo-1507238691740-187a5b1d37b8?auto=format&fit=crop&q=80&w=1000)

## 🎨 Design System
O foco deste projeto foi criar uma **Experiência Premium**. 
- **Estética:** Glassmorphism e Dark Mode minimalista.
- **Tipografia:** Uso de fontes modernas (Outfit/Inter) para legibilidade e impacto.
- **Interatividade:** Micro-animações que guiam o olhar do recrutador pelos meus destaques.

## 🚀 Stack Tecnológica
- **React (Vite):** Para uma navegação instantânea e modular.
- **Lucide React:** Iconografia consistente e semântica.
- **Pure CSS/Modules:** Estilização customizada sem dependências de frameworks de utilitários pesados, demonstrando domínio de CSS puro.
- **Responsive Architecture:** Grid dinâmico que se adapta perfeitamente a mobile e desktop.

## ✨ O que este projeto demonstra?
- **Domínio de Frontend Moderno:** Componentização, Hooks e performance.
- **Cuidado com UI/UX:** Atenção a espaçamentos, cores e feedback visual.
- **Habilidade de Curadoria:** Organização lógica de projetos por nível de complexidade.

## 🛠️ Como Explorar
1. `npm install`
2. `npm run dev`
