# Kanban & UX Focus 📋

Um gerenciador de tarefas premium que prioriza a fluidez da experiência do usuário e a simplicidade visual, inspirado nas melhores práticas de produtividade ágil.

![Preview do Kanban](https://images.unsplash.com/photo-1586281380349-632531db7ed4?auto=format&fit=crop&q=80&w=1000)

## 🎨 O Foco em UX
Neste projeto, o objetivo não foi apenas "fazer funcionar", mas "fazer sentir". Usando **Framer Motion**, cada movimento de task parece natural, reduzindo a carga cognitiva e tornando a organização de tarefas um processo prazeroso.

## 🚀 Stack Tecnológica
- **React:** Arquitetura baseada em componentes reutilizáveis.
- **Framer Motion:** Animações de layout e transições de estado fluidas.
- **Lucide React:** Icons minimalistas e consistentes.
- **Local Storage:** Persistência de dados offline zero-config.

## ✨ Destaques Técnicos
- **Persistence Layer:** Sincronização automática com o LocalStorage do navegador, garantindo que o usuário nunca perca seus dados ao atualizar a página.
- **Responsive Design:** Interface adaptável que funciona perfeitamente de desktops a dispositivos móveis.
- **Micro-interações:** Feedback visual imediato em todas as ações do usuário (adicionar, completar, deletar).

## 🛠️ Instalação
1. `npm install`
2. `npm run dev`
