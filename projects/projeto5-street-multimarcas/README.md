# Street Multimarcas — Elite Seminovos 🚗

Uma plataforma de vitrine digital de alta performance desenvolvida para concessionárias premium, focada em velocidade de navegação e facilidade de conversão.

![Preview Street](https://images.unsplash.com/photo-1583121274602-3e2820c69888?auto=format&fit=crop&q=80&w=1000)

## 🏁 O Projeto
O **Street Multimarcas** resolve o problema de performance comum em sites de classificados automotivos. A interface é extremamente leve, oferecendo filtros instantâneos sem necessidade de reload de página.

## 🚀 Tecnologias
- **Vite:** Build tool de última geração para performance máxima em desenvolvimento e produção.
- **Tailwind CSS:** Design system utilitário para uma interface moderna e customizável.
- **Framer Motion:** Gestão de estados de transição entre listagem e detalhes do veículo.
- **React Icons:** Conjunto de ícones vetoriais leves.

## ✨ Funcionalidades
- **Simulador de Financiamento:** Ferramenta integrada para cálculo de parcelas com base no valor do veículo.
- **Filtros Ultra-rápidos:** Filtragem instantânea por marca, categoria e faixa de preço.
- **Modal de Detalhes:** Visualização profunda de especificações técnicas do veículo em uma interface tipo "slide-over".
- **CTA para WhatsApp:** Integração direta para fechamento de venda.

## 🛠️ Execução
1. `npm install`
2. `npm run dev`
